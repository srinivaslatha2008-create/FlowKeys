# FlowKeys 🚀

A student practice app for typing, maths and basic physics.

## Included
- 60-second typing speed test with live WPM and accuracy
- Typing practice with character feedback
- Maths multiplication practice with score tracking
- Beginner-friendly physics lessons with real-life examples and formulas
- Responsive desktop/mobile UI

## Stack
Next.js + React + TypeScript. Ready for Vercel deployment.
